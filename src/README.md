# Pico RamOS · 桌面卡片系统

把桌面上的零零碎碎收进一套卡片里：每个软件、每个网址都能变成一张悬浮卡片，
各自带透明度、颜色、大小、位置；卡片靠拢时边缘自动吸附，拖远了就不吸附。
纯半透明设计，没有投影（透明窗上的投影会在四角露出方块，干脆不要）。

## 启动

双击 `start.bat`。它会按顺序找 electron：① 本目录 `node_modules`（先跑
`npm install electron`）② 本机 ai-agent-desktop 自带的 electron。

**首次启动不会甩你一脸卡片**——先弹「首次设置向导」：设好全局默认值
（透明度 / 颜色 / 显示模式 / 边缘吸附 / 点击穿透 / 开机自启），再勾选启用哪些卡片，
没勾的保持关闭。之后每张卡还能在自己的 ⚙ 里单独覆盖。
想改主意：托盘或管理面板里「重新运行首次设置向导」（重跑只追加新卡，不动你现有的）。

## 卡片类型

| 类型 | 说明 |
|------|------|
| 软件 | 导入任意 exe / bat / lnk，点卡片即启动，显示运行状态。空目标的「工作台」卡就是教学示例：去管理面板导入你自己的程序 |
| 网址 | 内嵌浏览器打开网页（Gmail / QQ 邮箱 / 163 等） |
| 视频（B 站） | **弹幕播放器小窗**：粘 BV 号/视频链接回车即播；也可切全页浏览，登录一次永久保持 |
| 学习卡 | 通用学习卡：自定义项目栏，见下 |
| 桌宠 | 默认加载文枢桌宠（需 hub 在跑，没跑会显示引导卡）；点卡片 ⚙ → 更换素材可导入自己的 3D / Live2D / 图片桌宠 |
| 桌面文件夹 | 仿手机桌面文件夹的**装饰性**整理卡：把桌面快捷方式收进卡片网格，点图标启动；顺序只记在卡片里，不碰电脑的文件系统 |

## 视频卡（B 站弹幕小窗）

默认就是「小窗播放器」：顶部地址栏粘贴 BV 号或视频链接（`BV1xx411c7mD`、
`https://www.bilibili.com/video/BV1xx...` 都认），回车加载嵌入播放器
（player.bilibili.com，**弹幕默认开启**，可手动关）。点「全页」进 B 站主页浏览，
webview 用独立分区（`persist:bili`）——扫一次码登录，卡片重启、系统重启都在登录态。
`↗` 用系统浏览器打开当前页。

## 桌面文件夹卡

- 添加入口：卡内 `＋ 添加快捷方式`（选文件），或把桌面上的 `.lnk / .exe / .bat / .cmd / .url` 直接拖进卡片。
- 点图标启动对应程序；拖 `⠿` 手柄在卡内排序；`✕` 移出卡片（**只移出卡片，不删文件**）。
- 卡内顺序存在 `cards.json` 的这张卡上——桌面右键怎么排序都影响不到这里，反之亦然。

## 学习卡（自定义项目栏）

不再是固定的雅思卡——每个项目用户自建，任何语言、任何主题：

- **项目**：顶部项目条可切换 / 新建；「管理 ▾」里改名称、切类型、导出/导入 JSON、删除。
- **背单词**：翻转卡 + 认识/不认识标记 + 乱序 + 键盘翻张，进度自动记。
- **磨耳朵**：条目 = 标题 + 音频链接（http 直接播）或本地文件路径（默认播放器打开），可单条循环。
- **口语/题库**：常用句/题目列表，🎲 随机抽一条，标「会了」。
- **素材分类**：自定义分类 + 条目（参考图卡片的分类法搬这里），点正文即复制。
- **导出/导入**：项目可导出成 JSON，发给别人一键导入；换机器也能带走。

## 桌宠自定义

卡片 ⚙ 设置里「更换素材」（文枢桌宠状态下也能直接导入，导入即切到自定义渲染）：

| 素材 | 格式 | 交互 |
|------|------|------|
| 3D 模型 | `.glb`（最稳；`.gltf` 需同目录素材一起选，会自动整包导入） | 拖动转视角、滚轮缩放、点击播动画（动画列表自动枚举，可指定）、可开自转 |
| Live2D | 选模型包里的 `model3.json`（整包导入） | 点击播动作（动作组自动枚举，可指定）、滚轮缩放、Shift+滚轮旋转 |
| 图片 | jpg / png / gif / webp | 滚轮缩放、Shift+滚轮旋转、点击弹台词 |

缩放/旋转/自转/互动都能存。「恢复默认桌宠」一键回到文枢桌宠。
导入的素材存放在 `assets/pet/<卡片id>/`，删卡片不会自动清（要清点「恢复默认桌宠」）。

## 全局开关（管理面板 / 托盘菜单）

- **显示模式**：
  - `卡片置顶`——各卡片自己决定置顶与否（老行为）。
  - `桌面组件`——所有卡片置底：在壁纸上面、其他窗口下面，像手机桌面挂件；
    切回置顶即恢复。置底用 `desktop-mode.ps1`（SetWindowPos HWND_BOTTOM）。
- **点击穿透**：开启后点击卡片会落到下方窗口，不挡事。**桌宠也遵守这个开关**
  （不再强制穿透，终于能点到了）；每张卡还能单独覆盖：卡片 ⚙ → 穿透
  （跟随全局 / 强制穿透 / 强制交互）。
- **边缘吸附（两个独立开关）**：`卡片互相吸附` + `对齐屏幕边缘`，阈值 14px，
  差得远就不吸。拖动时每次拖拽只吸一次（不振荡），松手再补一次对齐。
- **Ctrl+Alt+D**：临时拖动模式——穿透开着也能把卡片拖走，再按一次钉住。
- **开机自启（开关，默认关）**：托盘菜单或管理面板里切换。开启时只在 Startup
  目录写一个隐藏启动器（登录时自动找到 electron 并拉起本程序）；关闭即删除。
  便携版 electron 不能用系统登录项（会拉起一个空 electron），所以走 Startup 文件。

## 日常操作

- **移动**：拖卡片标题栏。松手时若与别的卡片/屏幕边缘相差 ≤14px 会自动对齐。
- **改大小**：拖卡片右下角把手。
- **透明度 / 颜色 / 置顶 / 穿透**：点标题栏右侧 ⚙。
- **管理**：托盘双击：导入软件、添加网址、学习卡、桌宠卡、B 站卡、桌面文件夹、
  编辑/删除、全局开关、开机自启。

## 给别人用

整个文件夹拷走即用（`assets/` 里的运行时已内置：model-viewer / pixi / Live2D）。
对方首次启动走向导，自己导入路径、勾选卡片——**起始种子卡不含任何个人路径**，
不会把某台机器的工作台打包进去。

⚠️ **外发前先删掉 `cards.json`**：它是本机配置，含你自己的软件路径。
删掉后对方首次运行自动进向导。`card-os.log` 也可以一起删。

## 配套：音乐唱片卡（独立小项目，不在本目录）

网易云 / QQ 音乐两张唱片卡是独立 Electron 小应用（`F:\job\netease-card`、
`F:\job\qqmusic-card`），用 Windows SMTC 读播放状态，进度/封面/歌词都有
（单曲循环重播会自动回绕进度）。它们跟着音乐客户端启动，但**开机不自启**——
看门狗是会话制：音乐在跑时拉一次卡片，你手动关掉卡片后本个会话不再拉起，
音乐重启才会再带出来。想要开机自动跟随：双击卡片目录里的 `toggle-autostart.bat`
打开开关（再双击关闭）。
